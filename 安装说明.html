请先读换一台电脑可能装不上 / 跑不起来

这个包只在作者本人的一台电脑上验证过（Windows + Node.js 22）。 作者不确定它在别的电脑、别的 DSH 版本上能不能正常工作。 下面这些是真实存在的风险，装之前请先看一遍：

  1. 只在 Windows 上测试过。一键安装脚本用了 mklink /J、fsutil、netstat、taskkill， 这些是 Windows 自带命令。macOS / Linux 用不了，得手动装。
  2. 只在 Node.js 22 上测试过。代码要求 Node 20+，但 20 和 21 没实测。
  3. 一键安装假设了 DSH 的目录结构。它去找 ~/.dsh/profiles/<名字>/node_modules/@dsh-external/。 如果你的 DSH 是别的装法（全局 npm、多个 profile、改过 DSH_HOME）， 脚本可能找不到位置或装错地方 —— 这种情况下会走「复制」兜底，或者直接报错让你手动处理。
  4. 批量打标签 / 缩放 / 截图用了 PowerShell 脚本（label.ps1、resize.ps1、grab.ps1）， 需要 Windows PowerShell。某些企业安全策略会禁用 Add-Type / 脚本执行， 那这几个功能会失效（其余功能不受影响）。
  5. 侧栏图标依赖 DSH 客户端的 window.__ModuleLoader__ 机制。 DSH 版本不同，界面可能不出现（工具调用仍然可用）。
  6. API 额度与限流是账号相关的。作者这边 Agnes 图片免费、视频队列常满； 你的账号状态、网络环境可能完全不同（例如 401 / 429 / 503）。
  7. 「导入图片生成视频」依赖第三方免费图床。作者实测只有 uguu.se 可用，其他几家在作者网络下都不通。你那边可能一家都不通 —— 这时需要自己配 publicBaseUrl 或 uploadEndpoint。
  8. 素材/配置不会自动迁移。插件的数据目录是 ~/.dsh/gpt-image/， 安装脚本会自动创建，不会覆盖你已有的配置；但也不会把你原有的 Key 带过来。

结论：当作「可以试试」的东西，而不是「装上一定能用」。 装完如果侧栏没出现图标 / 工具报错，先看下面的 排错，再看包里的 README.md（有大量实测记录）。

一键安装

  1. 解压这个 zip（别在压缩包里直接双击运行，要先解压到硬盘上，比如 D:\dsh-gpt-image）。
  2. 先做一次环境检查（不改任何东西、不重启）： 
    一键安装.bat check
    或者右键 一键安装.bat → 以管理员身份运行也行（其实不需要管理员权限）。 检查项：操作系统 / Node 版本 / DSH 目录 / 插件自检（工具数、侧栏配对）。
    全部 [OK] 再往下走。
  3. 正式安装：双击 一键安装.bat（不带参数）。 它会：建目录链接 → 自检 → 重启 DSH。
    它会重启 DSH —— 当前网页会断开（会话不会丢）。重启前有 5 秒倒计时，按 Ctrl+C 可以取消。 如果你不想让它重启，可以先设环境变量 AUTO_NORESTART=1，再单独双击 重启DSH并加载生图插件.bat。
  4. 刷新浏览器：打开 http://127.0.0.1:3080 并按 Ctrl+F5。
    装好的标志：左侧栏出现 余额 / 生图 / 生视频 / 自动化 四个图标。 没有？看下面的 排错。
  5. 配 API Key —— 见下方向下滚，每个服务商都有「去申请」按钮，点了直接跳官网。

不想用一键脚本？手动装（三步）

REM 1) 把插件放到 DSH 的 node_modules 里（目录链接，改代码即时生效）
mklink /J "%USERPROFILE%\.dsh\profiles\web\node_modules\@dsh-external\dsh-gpt-image" "D:\你的路径\dsh-gpt-image"

REM 2) 自检
cd /d D:\你的路径\dsh-gpt-image
npm test
node scripts\inventory.mjs

REM 3) 重启 DSH（双击 重启DSH并加载生图插件.bat），然后浏览器 Ctrl+F5

把 Key 填进插件

方式 A · 让 AI 帮你配（在 DSH 对话里直接说）

把下面这段里的 sk-你的key 换成你自己的，然后粘进对话：

config(action="set_profile", profile={
  "id": "agnes-2.5-flash",
  "name": "Agnes Image 2.5 Flash（免费档）",
  "provider": "agnes",
  "baseUrl": "https://apihub.agnes-ai.com/v1",
  "apiKey": "sk-你的key",
  "model": "agnes-image-2.5-flash",
  "apiMode": "images",
  "pricePerImage": 0
})
config(action="set_active", profile_id="agnes-2.5-flash")
config(action="test", profile_id="agnes-2.5-flash")

方式 B · 面板里填

侧栏「生图」→ 配置区 → 填 baseUrl / apiKey / model → 保存。 侧栏「余额」页能看到「还能不能花钱、花了多少」。

方式 C · 导入现成模板

config(action="import", path="examples/agnes-config.json")

包里的 examples/agnes-config.json 包含 Agnes 图片 + 视频两套配置，apiKey 是空的，自己填。

排错：装完不对劲怎么办

现象原因 / 怎么办
侧栏看不到那四个图标 没重启 DSH。双击 重启DSH并加载生图插件.bat，再 Ctrl+F5。 还不行 → DSH 版本差异导致客户端没加载（工具调用仍可用）。
侧栏图标点了没反应 该页缺少对应的 main 面板。跑 node scripts\inventory.mjs， 看到「✓ 侧栏 id 与 main key 全部配对」才算正常。
一键安装说「找不到 profiles 目录」 DSH 的安装位置不是默认的。先确认浏览器能打开 http://127.0.0.1:3080， 再设环境变量 DSH_HOME 指向你的 .dsh 目录，重跑。
一键安装说「创建链接失败」 它已经自动改用「复制」方式。复制方式下改插件代码不会即时生效。
npm test 有红 插件本体损坏（解压不完整？）。重新解压 zip 再试。
报 401 / 403 Key 无效、过期、没权限或没余额。跑 config(action="test") 探连通。
报 429 限流（Agnes 免费档视频尤其明显）。等额度恢复或升级，重试没用。
报 503 video_queue_full 视频队列满，免费档常见且可能持续很久。插件会自动退避重试。
报 size must be 720P Agnes 视频固定 720P，要别的分辨率得换模型。
报 media URL could not be downloaded 素材链接 Agnes 取不到。免费图床可能失效 → 换 publicBaseUrl / uploadEndpoint。
想确认插件完好 npm test（557 个测试应全过）+ node scripts\inventory.mjs（27 工具 / 32 路由 / 4 页配对）。
